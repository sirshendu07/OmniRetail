# OmniRetail — Frontend Storefront & Admin Portal

This directory is reserved for the OmniRetail frontend web application (Next.js / React, Tailwind CSS, TypeScript).

## Roadmap
- **Customer Storefront:** Product browsing, semantic AI search, cart, and checkout with Razorpay.
- **Store Manager Portal:** BOPIS (Buy Online, Pick Up in Store) order fulfillment, shelf inventory adjustments, and inter-store stock transfer management.
- **HQ Executive Dashboard:** Real-time GMV analytics, network inventory health, and channel revenue split metrics.
